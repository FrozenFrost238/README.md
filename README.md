# Hi, I'm Pratyusha 👋

**Threat Analyst** based in Hyderabad, India. CEH v13 certified, working in a live SOC on email security for a Microsoft client, and building toward proactive, hypothesis-driven threat hunting.

I spend my days triaging phishing, spoofing and malware alerts, and I like turning what I see in the queue into better detections, so the same attack gets caught faster (and with fewer false positives) the next time.

## 🔍 What I do

- **Alert triage and investigation:** L1/L2 email security alerts using Microsoft Defender for Office 365 (MDO) and Exchange Online Protection (EOP)
- **Phishing and IOC analysis:** email headers, URLs, attachments and logs; blocking malicious senders and domains org-wide
- **Detection tuning:** writing detection rules and mail flow policies to block suspicious URLs/domains and cut false positives
- **MITRE ATT&CK mapping:** tying findings to real techniques to spot detection gaps
- **Incident documentation:** clear write-ups of findings, remediation steps and rule changes for stakeholders and compliance
